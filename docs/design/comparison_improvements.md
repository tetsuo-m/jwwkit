# Jw_cadの保存時に変わる属性の印付け案

> 設計の記録であり、実装済みの機能ではありません。

独立した図面比較で、既知の保存時の変化を識別しやすくするための提案です。 現行compare_drawingsの分類/差一覧/complete判定を変えず、正規化を推測して無視する処理も追加しない。

将来の案：明示的に選べる印付けを用意し、承認済みのJw_cadの保存時正規化に一致する差を、通常の差として残したまま見分けられるようにする。例は多角形ソリッドの線種31（SXF continuous）→1（標準実線）。

- 根拠を取得した要素種別・欄・変更方向・条件を厳密に限定する。例では多角形ソリッドのみ、他の色・座標・全属性は一致必須。円ソリッド/他の線種へ広げない。
- 印には規則名/根拠/適用条件を残し、元の旧新値と属性差の分類を削除しない。印を一致・受入れ合格・承認の代わりにしない。
- 未承認の差や条件の一部しか一致しない差には印を付けない。既存GUI監査の限定許容と、独立比較における差の表示は区別する。
- 実装時は別途設計/利用者確認を経て、既存結果を遡って書き換えない。現時点で選択引数や印のJSON欄は存在しない。
