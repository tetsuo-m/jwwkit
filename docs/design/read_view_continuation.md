# 状態を持たないページ継続の検討

> 設計の記録であり、実装済みの機能ではありません。

技術的には可能。同じファイルを毎回開き、SHA、参照スキーマ、Reader/幾何/検索/文字対応表の規則版、query/単位/許容値/順序を固定し、最後に返した保存番号/子経路を再計算で見つければ、ビューを保持しなくても続きを作れる。

ただしファイル参照だけでは検索条件や規則が固定されない。候補tokenには上の条件のハッシュと位置も必要。最近検索の同距離全件をページ化するなら、毎回全体最小距離の再計算が必要で、SHAが同じでも計算量が消えるわけではない。処理上限で走査が未完なら完全な続きとは呼ばない。

tokenの単なるSHAチェックは認証ではない。強い改ざん検知を保証するなら署名鍵等の共有が必要で、完全に設定すら持たない方式とは別の設計になる。読み取りの再計算で整合性を検証する範囲と、署名で保証する範囲を分けて相談する。現在の読取りビューはファイル参照の再取得までを提供する。
